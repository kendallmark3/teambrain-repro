# L’Oréal AI Beauty Decision Engine

## 🚀 Quick Start (Run from Claude or Terminal)

1. Open terminal in this folder
2. Navigate to frontend:
   cd frontend/loreal-demo

3. Install dependencies:
   npm install

4. Start app:
   npm run dev

5. Open browser:
   http://localhost:5173

---

## 🎯 Demo Goal
Show difference between:
- Uncontrolled AI (random outputs)
- Intent-driven AI (consistent, structured results)
